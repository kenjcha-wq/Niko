象库 · 轻工作台 (XiangKu Workstation)
「象库 · 轻工作台」是象库矩阵（XiangKu Matrix）中的轻量级工作场景入口。它不是传统的企业 OA 或机械的待办清单，而是你在日常工作过程中捕捉信息、沉淀经验、管理知识、打造个人“数字分身”的核心工具。

一、 核心功能定位
工作流 Daily Stream（告别死板待办）：按时间轴实时记录工作流水、阶段进展、突发异常与工作心得，支持 #标签 快速索引。

全分区知识库（支持文件与 PDF 解析）：集中沉淀流程规范（SOP）、制度规章、技术文档、摘录文献、项目资料与工作笔记。内置纯前端安全解析引擎，支持直接上传并提取 PDF、TXT、MD 等文档正文入库。

个人资料库（数字分身底座）：记录长期属于你个人的 7 大成长维度：

档案：核心身份与目标（自动注入 AI 上下文）。

能力：专业、工具、管理及沟通技能成长记录。

经验：结构化复盘（场景、问题、解法、总结）。

模板：个人复用的总结与汇报模板（支持一键复制）。

联系人：关键协作关系与合作记录。

方法论：长期验证有效的时间管理与思考框架。

成长轨迹：个人日志、认知迭代与未来计划。

智能体自动化中枢（Agent Engine）：内置自动总结推流、经验萃取等工作流管道，支持自定义创建专属智能体（配置 System Prompt 与数据权限）。

NIK 全域通用 AI 终端：随时随地通过浮窗与大模型进行通用对话、编码协助、逻辑推理，并具备一定的本地系统操作能力。

二、 矩阵互联与扩展
象库矩阵导航：

象语（心智表达与自然语言）

象库（总知识中心与资料汇聚）

象库 · 写字台（专注长文创作空间）

飞书多轨联动：支持通过自定义机器人 Webhook 或自建应用 API，一键将工作总结与核心记录推送到飞书群或私聊。

完全自主的本地数据权：

基于 localStorage 零后端、零维护，数据仅保存在你的浏览器本地。

支持增量合并导入恢复与全量 JSON 备份导出，换设备或清理缓存永不丢失。
